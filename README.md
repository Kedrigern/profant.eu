# profant.eu

Static site generated by [Zola](https://www.getzola.org/)

**Note:** This repository uses [Git LFS](https://git-lfs.com/) for storing large binary files (images, PDFs, etc.). Make sure you have it installed before cloning.

## Prerequisites

1. Install [Zola](https://www.getzola.org/)
2. Install [Git LFS](https://git-lfs.com/): `git lfs install`

## Usage

```bash
zola serve  # preview
zola build  # build into public dir
```

**Troubleshooting:** If you don't see images when running `zola serve` locally, your LFS files might not be downloaded. Fix this by running:

```bash
git lfs fetch
```

## Deployment

Deployment is [automatic](.github/workflows/deploy.yml) after pushing to main branch in repository.
